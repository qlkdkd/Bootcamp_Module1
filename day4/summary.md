# 파일
- 파일 생성: `open(파일명/경로, 모드)`
     - 파일 객체 반환
- 모드 종류
    - r: 읽기
    - w: 쓰기
    - a: 기존 파일에 새 내용 추가
- f.close(): 파일 닫기
    - `with open(파일명/경로, 모드) as f`를 쓰면 해당 블록 내에서만 파일을 쓸 수 있음
        - 블럭 벗어나면 파일 닫음
- w
    - `f.write(문자열)`: 파일에 문자열 쓰기
- r
    - `f.readline()`: 파일 1줄 읽어서 문자열로 반환
    - `f.readlines()`: 파일 모든 줄을 읽어서 리스트로 반환
    - `f.read()`: 파일 모든 줄 읽어서 문자열로 반환
- a
    - a로 파일을 읽고 `write()` 쓰면 기존 내용 뒤에 내용 추가

# 클래스
- 클래스: 객체의 설계도
- 객체: 상태와 메서드를 가진, 클래스로 만들어진 것

## 클래스의 구조
```py
class 클래스명:
    # 생성자
    def __init__(self, ...):

    # 메서드
    def 메서드명():

```

- 상태: 객체 내부에 있는 변수(값). 생성자 안에 정의
- 메서드: 객체의 행위. 클래스 안에 함수 형태로 정의

- 클래스 호출: `변수명=클래스명()` 형태로 선언
    - 생성자에 self 외의 매개변수가 있으면 인수와 함께 호출
- 메서드 호출: `객체명.메서드()` 형식으로 호출

## 객체
- 같은 클래스로 선언한 두 객체는 서로 다른 존재
