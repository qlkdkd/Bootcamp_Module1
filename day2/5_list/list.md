# 리스트
```py
리스트_변수 = [요소1, 요소2, 요소3, ...]
```
- 리스트: 여러 요소를 묶어서 쓰는 데이터 타입
- 대괄호 안에 여러 요소 입력
- 공백 리스트 생성: [] 또는 list() 함수 이용
```py
a = []
print(a)

a = list()
print(a)
```
```
[]
[]
```

## 리스트의 인덱싱
- 기본은 문자열과 동일
- 이중 리스트에 접근할 때 리스트_변수[행_인덱스][열_인덱스]로 접근
```py
a = [1, 2, 3, ['a', 'b', 'c']]
print(a[1])
print(a[3])
print(a[3][1]) # a의 인덱스 3의 인덱스 1
```
```
2
['a', 'b', 'c']
b
```
- 리스트 안에 리스트 넣기 가능
```py
a = [1, 2, ['a', 'b', ['Life', 'is']]]
```

## 리스트의 슬라이싱
- 얘도 기본은 같음
```py
a = [1, 2, 3, 4, 5]
print(a[0:2])
```
```
[1, 2]
```
- 중첩된 리스트에서 슬라이싱 역시 마찬가지
```py
a = [1, 2, 3, ['a', 'b', 'c'], 4, 5]
print(a[3][0:2])
```
```
['a', 'b']
```

## 리스트 연산
- 리스트 + 리스트: 리스트 이어붙임
- 리스트 * 정수: 리스트를 정수만큼 반복
- len(리스트): 리스트 길이 반환

## 리스트 수정과 삭제
- 리스트 수정/삭제 가능
- 리스트 요소 삭제 방법: del 리스트[삭제할 인덱스]
```py
# 수정
a = [1, 2, 3]
a[2] = 4
print(a)

# 삭제
a = [1, 2, 3]
del a[1]
print(a)
```
```
[1, 2, 4]
[1, 3]
```

## 리스트 관련 함수
### 요소 추가
- append(요소): 리스트 맨 뒤에 요소 추가
```py
a = [1, 2, 3]
a.append(4)
print(a)
```
```
[1, 2, 3, 4]
```

### 정렬
- sort(): 리스트 작은것부터 큰 순으로 정렬
```py
a = [1, 4, 3, 4]
a.sort()
print(a)
```
```
[1, 3, 4, 4]
```
- 알파벳 순으로도 정렬 가능
```py
a = ['a', 'c', 'b']
a.sort()
print(a)
```
```
['a', 'b', 'c']
```
#### 역순 정렬
sort()에 reverse=True 넣어주기
```py
a = [1, 4, 3, 2]
a.sort(reverse=True)
print(a)
```
```
[4, 3, 2, 1]
```

### 뒤집기
- reverse(): 현재 리스트 그대로 거꾸로 뒤집음
```py
a = [1, 4, 2, 3]
a.reverse()
print(a)
```
```
[3, 2, 4, 1]
```

### 인덱스 함수
- index(x): 리스트에 x가 있으면 x의 인덱스값 반환
    - 찾으려는 값이 없으면 에러 발생
    - 찾으려는 값이 여러개면 맨 앞에 있는 인덱스 반환
```py
a = [1, 2, 3]
print(a.index(3))
print(a.index(0)) # 에러!
```

### 특정 위치에 삽입
- insert(a, b): 리스트의 a번째 위치에 b 삽입
```py
a = [1, 2, 3]
a.insert(0, 4)
print(a)
```
```
[4, 1, 2, 3]
```

### 요소 제거
- remove(x): 리스트에서 첫번째로 나오는 x 제거

```python
a = [1, 2, 3, 1, 2, 3]
a.remove(3)
print(a)
```
```
[1, 2, 1, 2, 3]
```

### 꺼내기
- pop(): 리스트 맨 마지막 요소 반환하고 그 요소 삭제

### 개수 세기
- count(): 리스트 안에 x가 몇 개 있는지 세기

### 확장
extend(x): 기존 리스트에 새 리스트 x를 더함
